Introduction & Terminology

There is a lot of terminology in this chapter to understand.
  • VO = Virtual Observatory
  • TAP = table access protocol . TAP services enable complex queries of tables using ADQL.
  • ADQL = astronomical data. query language
  • ObsCore = core components of Observation Data Model
  • Data model = A standard logical structure for a type of dataset; more flexible and general than a data format.
  • ObsTAP = TAP service that serves ObsCore tables
  • SCS = simple cone search.
There are myriad places on the web to learn more about TAP queries and ADQL, as well as all the rest of the VO standards and protocols. We just provide a brief overview here in the context of this tool.

Firefly can help you interactively create ADQL which then you can copy and use in your own code elsewhere.

By using TAP and ObsTAP queries, you can use IRSA (or someone else's) services to talk to other archives that also comply with these standards, world-wide.

This section assumes you already know how to work with tables in Firefly.
